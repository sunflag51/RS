米国11セクター RS ダッシュボード（GitHub + Streamlit Cloud版）
================================================================

このフォルダーのファイルをGitHubリポジトリの一番上（root）へアップロードすると、Streamlit Community Cloudから起動できます。iPhoneにはPythonをインストールせず、公開後のURLをSafariで開いて使用します。

ファイル構成
------------
main.py                  アプリ本体（Streamlitの起動ファイル）
requirements.txt         必要なPython部品
.streamlit/config.toml   白背景と公開サーバー用設定
README_日本語.txt         この説明
.gitignore               仮想環境などの除外設定

GitHubからiPhoneで使うまで
--------------------------
1. GitHubで新しいリポジトリを作ります。
2. このZIPを展開し、上記ファイルをフォルダーごとではなく、リポジトリ直下へアップロードします。.streamlitフォルダーもそのまま置きます。
3. Streamlit Community Cloudへログインし、GitHubのリポジトリ連携を許可します。
4. 「Create app」で対象のRepositoryとBranchを選び、Main file path に main.py を指定してDeployします。
5. 起動が完了したら、表示されたアプリURLをiPhone 17のSafariで開きます。
6. Safariの共有メニューから「ホーム画面に追加」を選ぶと、次回からアイコンで開けます。

iPhone向けの調整
-----------------
・スマートフォンで読めるよう、ページを中央寄せにし、指標カードを2列ずつ配置しました。
・初回はサイドバーを閉じて表示します。期間・比較日数・銘柄の変更は画面左上（またはメニュー）のサイドバーを開いて行います。
・グラフは画面幅に合わせて表示されます。銘柄を少なくすると線や凡例を読みやすくできます。

アプリ内容
----------
XLB, XLC, XLE, XLF, XLI, XLK, XLP, XLRE, XLU, XLV, XLY の11セクターETFをSPYと比較します。SPY比RSライン、期間騰落率、SPYとの差、相対強度ランキング、出来高比、ヒートマップを表示します。

注意
----
・GitHubへのアップロードとStreamlit CloudでのDeployが完了して初めて、iPhoneから開けるURLができます。このZIPだけでiPhone内にアプリをインストールして起動する形式ではありません。
・株価はYahoo Finance経由で取得します。初回起動時やアクセス集中時にデータ取得が遅れたり、提供元の制限で一時的に取得できない場合があります。画面の再実行で再取得できます。
・出来高比は売買の活発さの補助指標で、ETFの実際の資金流入額ではありません。
・アプリは投資助言や売買推奨ではありません。
